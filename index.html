This page lists HaTi's file paths, its endpoints that work without logging in, and its known weaknesses. It is a separate service on a private URL and requires an access token. It reads HaTi's source from GitHub, and asks the running HaTi for nothing but caps and counts through one read-only endpoint — switch that off any time by clearing MAPPER_TOKEN in HaTi's environment.
