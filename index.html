Worth knowing. Your custom templates are stored inside the settings record rather than as their own rows. Every time anyone changes a setting, all template text is rewritten with it. Fine at two templates. Not fine at thirty with version history.

Not finished yet

Gathered from your README, SECURITY.md and the notes left in the code.

No real identity checks on signing
IPRS lookups and CAK-accredited signatures aren't connected. The product says so on screen, which is the right thing to do — but it caps what you can charge for.
README · honest limitations
Scanned documents can't be read
A scan or a photo produces no text, so the details have to be typed by hand.
views/contract.js · extractDocText
Word files fail silently
The picker accepts them; nothing can read them. They land as empty records.
views/contract.js · extractDocText
Usage counters live in memory
A restart resets the daily AI allowance to zero. Running on more than one server would multiply every limit.
server/server.js · rate limiters
One workspace only
No multi-tenancy and no billing, so this can't yet be sold as a hosted service.
MULTITENANCY-NOTES.md
Data protection paperwork
ODPC registration not done. Needed before holding other companies' contracts in Kenya.

Open to the public

Four things work without logging in. Worth knowing exactly what they are.

#share=t:…
Counterparty review portal
Opens one contract for one recipient. Accepts a single response, then closes. Expires after 14 days.
#advice=new
Advice request intake
Anyone can submit a legal services request and see the rate card and queue load. Quotes are worked out on the server so the browser can't be trusted with pricing.
#advice=t:…
Request tracking link
Shows one requester their own pipeline stage and fee estimate.
signing code
Email one-time code
Verifies a counterparty's identity before they sign.

Six files are past the comfortable line. views/contract.js holds the workspace, the uploads, the PDF reader and the signing flow — four jobs in one file. Splitting it would make every future session on documents faster and safer.
